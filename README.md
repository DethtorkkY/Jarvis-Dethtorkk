# JARVIS для Windows

После входа в Windows приложение произнесёт приветствие, а затем будет постоянно слушать микрофон. Когда услышит «Jarvis» или «Джарвис», оно ответит: «Я пока что в разработке».

## Установка

Откройте PowerShell в этой папке и выполните:

```powershell
.\Install.ps1
```

Установщик добавит ярлык в автозагрузку текущего пользователя. После этого можно выйти из учётной записи и войти снова. JARVIS работает скрытно и распознаёт слово `Jarvis` локально, без интернета.

Скрипт добавляет ярлык только в автозагрузку текущего пользователя. Для удаления выполните:

```powershell
.\Uninstall-Autostart.ps1
```

Для проверки без перезагрузки запустите `python jarvis.py` в PowerShell. Текст приветствия и ответ настраиваются в `jarvis.py`.

## Игровой режим

Скажите: «Джарвис». После вопроса «Чем займёмся, сэр?» скажите, например, «поиграть», «игра», «катка» или «гамать». Затем назовите Майнкрафт, Роблокс, Стим или Эпик. JARVIS откроет соответствующий игровой клиент.
