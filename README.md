# JARVIS для Windows

После входа в Windows приложение произнесёт приветствие, а затем будет постоянно слушать микрофон. Когда услышит «Jarvis» или «Джарвис», оно ответит: «Я пока что в разработке».

## Установка

Откройте PowerShell в этой папке и выполните:

```powershell
.\Install.ps1
```

Установщик добавит ярлык в автозагрузку текущего пользователя. После этого можно выйти из учётной записи и войти снова. JARVIS работает скрытно и распознаёт слово `Jarvis` локально, без интернета.

Скрипт добавляет ярлык только в автозагрузку текущего пользователя. Для удаления выполните:

```powershell
.\Uninstall-Autostart.ps1
```

Для проверки без перезагрузки запустите `python jarvis.py` в PowerShell. Текст приветствия и ответ настраиваются в `jarvis.py`.

## Игровой режим

Скажите: «Джарвис». После вопроса «Чем займёмся, сэр?» доступны команды:

- «игра», «поиграть», «катка» или «гамать» — выбор игрового клиента;
- «запусти Майнкрафт / Роблокс / Стим / Эпик» — запуск сразу;
- название установленной игры Steam — запуск конкретной игры голосом;
- «что запущено?» или «какая игра?» — определение известных запущенных игр;
- «закрой игру» или «закрой Майнкрафт» — закрытие известной игры;
- «Competitive», «Streaming», «Chill» или «AFK» — переключение игрового профиля.

## Профили и новые игры

Файл `game_profiles.json` хранит профили и игры. Профили меняют схему питания Windows: `Competitive` — высокая производительность, а остальные — сбалансированный режим. В поле `launch` можно добавить абсолютные пути к программам, которые нужно открывать вместе с профилем (например, OBS для `Streaming`).

JARVIS читает названия установленных игр Steam автоматически из файлов Steam. Для автоматического определения игры и корректного голосового закрытия добавьте для новой игры в `games` её `aliases`, список имён процессов `processes` и профиль `profile`.
